#### Data and tools

<a href="https://github.com/ethanez713/spend_visualizer"><img src="https://raw.githubusercontent.com/ethanez713/spend_visualizer/main/docs/img/overview.png" alt="spend_visualizer" width="50%"></a>

- **[spend_visualizer](https://github.com/ethanez713/spend_visualizer)**: budgeting services want your bank login and keep your data. This keeps the whole pipeline on your machine: Plaid sync, an append-only ledger, rule-based categories, local dashboards. <sub>Python · DuckDB · Streamlit</sub>
- **[claude-code-toolkit](https://github.com/ethanez713/claude-code-toolkit)**: long AI coding sessions fail in repeatable ways. Hooks, skills and an MCP server that stop those failures and measure whether each fix worked. <sub>Python</sub>
- **[claude-autoresume](https://github.com/ethanez713/claude-autoresume)**: Claude Code stops at its usage limit and waits for a person. This resumes every session when the limit resets. <sub>Bash · tmux</sub>
- **[adbconnect](https://github.com/ethanez713/adbconnect)**: Android switches wireless debugging off at every reboot and Wi-Fi change. One command brings it back. <sub>Kotlin · Bash</sub>
- **[sts2-couch-coop](https://github.com/ethanez713/sts2-couch-coop)**: Slay the Spire 2 co-op is online only. This runs it for two people on one PC, each with their own window and pointer. <sub>C# · Harmony</sub>
